Binance Price Widgets

Real-time cryptocurrency tracking scripts built using the Binance API.

1. Scrolling Price Ticker (Ticker Tape)

Creates a scrolling price bar that supports multiple symbols and can be placed at the top of the page or anywhere you like.

LIVE PREVIEW

How to Use

Paste the following code snippet anywhere in your HTML page:

<script 
  src="https://cdn.jsdelivr.net/gh/madenix/Crypto-Api-Widgets@main/Binance/tickerTapeWidget.js" 
  data-bases="btc,eth,bnb,sol,xrp,ada" 
  data-quote="usdt"></script>

2. Single Live Price Card

A minimal price widget used to highlight a specific trading pair.

LIVE PREVIEW

How to Use

Use the following structure to display a single cryptocurrency:

<script 
  src="https://cdn.jsdelivr.net/gh/madenix/Crypto-Api-Widgets@main/Binance/tickerWidget.js" 
  data-base="btc" 
  data-quote="usdt"></script>
