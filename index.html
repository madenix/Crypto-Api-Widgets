Binance Price Widgets

Binance API kullanarak hazırlanan gerçek zamanlı kripto para takip scriptleri.

1. Kayan Fiyat Şeridi (Ticker Tape)

Çoklu sembol desteğiyle ekranın üstünde veya istediğiniz bir alanda kayan fiyat bandı oluşturur.

CANLI ÖNİZLEME

Nasıl Kullanılır?

Aşağıdaki kod snippet'ini HTML sayfanızın herhangi bir yerine yapıştırın:

<script 
  src="https://cdn.jsdelivr.net/gh/madenix/Crypto-Api-Widgets@main/Binance/tickerTapeWidget.js" 
  data-bases="btc,eth,bnb,sol,xrp,ada" 
  data-quote="usdt"></script>

2. Tekil Canlı Fiyat Kartı

Belirli bir işlem çiftini vurgulamak için kullanılan minimal fiyat kutusu.

CANLI ÖNİZLEME

Nasıl Kullanılır?

3. Live Price List Widget

Lists multiple cryptocurrencies in a structured table-style layout. Prices and 24-hour percentage changes update in real time. Colors indicate whether the price is above or below its 24-hour opening value.

LIVE PREVIEW

How to Use

Insert the following script tag anywhere in your HTML page:

<script
  src="https://cdn.jsdelivr.net/gh/madenix/Crypto-Api-Widgets@main/Binance/tickerList.js"
  data-bases="btc,eth,bnb,sol,xrp,ada,link,aster,algo,atom,avax,bch,dash,doge,dot"
  data-quote="usdt"></script>
